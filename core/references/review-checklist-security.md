# レビューチェックリスト: security（詳細）

`core/roles/evaluator.md`「観点（focus）」の対応表から参照される。
**`security` 観点で起動された evaluator と、観点未指定（全観点）で起動された evaluator だけが
このファイルを読む。**

#### セキュリティ

- [ ] 認証・認可が適切
- [ ] インジェクション対策がされている
- [ ] シークレットのハードコードがない
- [ ] XSS対策がされている

#### テスト安全性

- [ ] テスト実行時に実ユーザーにメールが送信される可能性がないこと（テスト用受信アドレスが未設定の場合はREQUEST_CHANGES）
- [ ] 本番環境のデータに一切触れていないこと（本番DBへの接続設定が含まれていないこと）
